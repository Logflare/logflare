# Elastic OTLP

The Elastic OTLP backend is **ingest-only**. It exports logs via [OTLP](https://opentelemetry.io/docs/specs/otel/protocol/) HTTP/protobuf to Elastic Observability.

This type (`elastic_otlp`) is a branded alias of the [OTLP](/backends/otlp) adaptor. Configuration and delivery behavior match OTLP exactly.

:::info
This is separate from the [Elastic](/backends/elastic) Filebeat HTTP backend (`elastic`).
:::

## Behaviour and configurations

### Configuration

The backend can be configured with the following options:

- `:endpoint` (string, required) - The Elastic managed Supabase OTLP endpoint (ends with `/supabase/v1/logs`), e.g. `https://abc.ingest.us-central1.gcp.elastic.cloud:443/supabase/v1/logs`.
- `:protocol` (string) - Fixed to `"http/protobuf"` for managed Elastic OTLP; not user-configurable in the Supabase UI.
- `:gzip` (boolean) - Enables gzip compression for the request. Defaults to `true`.
- `:headers` (map) - A map of additional headers to set when making the HTTP request. Defaults to an empty map.
